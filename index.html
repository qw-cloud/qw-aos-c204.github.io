HOW I BUILD

Research code should have a point of view.

DATA

Longitudinal by default

A snapshot answers “what is happening?” A panel answers “what is changing?” I prefer systems that accumulate evidence over time.

MODELS

Transparent before ornate

Scores, assumptions, and uncertainty should be inspectable. Complexity should earn its place rather than decorate the project.

INTERFACES

Designed for interpretation

A useful research interface should expose the state of the system, not bury it under plots and controls.

ONGOING
